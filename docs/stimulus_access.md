# Stimulus access

The emotional dot-probe task uses materials selected from the International Affective Picture System (IAPS) and the Chinese Facial Affective Picture System (CFAPS).

The stimulus images are not redistributed in this repository or in the controlled EEG package because use remains subject to the original databases' terms. Researchers must obtain the images from the relevant rights holders.

The formal dataset documentation may provide permitted stimulus identifiers, pairing information, condition labels, and reconstruction guidance. Those materials must not contain or reproduce the restricted images themselves.
