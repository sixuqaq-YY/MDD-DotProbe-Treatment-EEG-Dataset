# Reviewer access

Scientific Data reviewers can anonymously and immediately download the static, de-identified representative package from the public GitHub Release:

[Download the reviewer sample (v0.1.0)](https://github.com/sixuqaq-YY/MDD-DotProbe-Treatment-EEG-Dataset/releases/download/reviewer-sample-v0.1.0/MDD-DotProbe-reviewer-sample-v0.1.0.zip)

The package includes one HC baseline visit, one paired NOCCS participant, and one paired CCS participant. It contains processed continuous EEG, available task-event tables, cleaned ERP derivatives, minimum interpretation metadata, and a file manifest.

Archive SHA-256: `d4e939d410a619b1e6c3248ee1431dd736cc70057a2ce42334bae65e95b379fa`

No login, password, token, author contact, research proposal, or institutional approval is required for this reviewer sample. The archive is a GitHub Release asset and is intentionally not stored in the tracked Git tree. It contains no participant source identifiers.

The complete dataset remains controlled access under `DATA_ACCESS.md` and `DATA_USE_AGREEMENT.md`.
