# Reviewer access

Scientific Data reviewers receive a separate, static, de-identified representative package through the instructions embedded in the revised manuscript.

The package is designed to include one HC baseline visit, one paired NOCCS participant, and one paired CCS participant. It includes the minimum available EEG, behavioral, derived-data, and metadata files needed to evaluate organization and reuse, plus SHA-256 checksums.

The public repository does not store reviewer-only tokens, passwords, participant source identifiers, or the reviewer archive itself. The reviewer link must work anonymously and immediately without contacting the authors.

The complete dataset remains controlled access under `DATA_ACCESS.md` and `DATA_USE_AGREEMENT.md`.
